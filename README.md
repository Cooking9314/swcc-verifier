# Проверка отчёта .swcc

Одностраничный верификатор отчётов Sunrise Worlds Cheats Checker (`.swcc`).
Работает целиком в браузере: файл отчёта разбирается на клиенте, никуда не
отправляется.

- `site/index.html` — разметка, `site/index.css` — оформление,
  `site/core.js` — разбор `.swcc` и печать, `site/ui.js` — интерфейс.
  Сборки нет, внешних зависимостей нет (шрифты, CDN, аналитика отсутствуют);
  страница запрашивает только эти четыре своих файла.
- Скрипты подключены обычными `<script src>` (не модулями), поэтому страница
  работает и по `file://`, и по HTTPS.
- Печать (`!SEAL!`) считается двумя движками: `crypto.subtle` в безопасном
  контексте и независимой pure-JS реализацией SHA-256 (FIPS 180-4) — вторая
  нужна там, где безопасного контекста нет.
- `<meta name="robots" content="noindex">` — страница не должна попадать в
  поиск.

## Публикация

`site/` выкладывается на GitHub Pages через `.github/workflows/pages.yml`
(источник Pages: GitHub Actions). Push в ветку `master` запускает деплой
автоматически.

## Соответствие формату

Алгоритм печати и порядок текстов проверок повторяют `Report::verify` из
приложения:

```
payload = все символы между !PAYLOAD-BEGIN! и !PAYLOAD-END! без пробельных
seal    = hex( SHA-256( "sunrise-worlds-swcc-seal-v1" + payload ) )[0..12]
```

Если меняешь формат отчёта в приложении — меняй здесь синхронно.
